Controller = receives the request and pass it to the appropriate part of the application.

Service = decides what should happen

i.e.        Check that the product exists
            Check that there's enough stock
            Check whether the product is already in the cart
            Increase quantity if it already exists
            Calculate totals
            Save the changes

Repository = talks to the database to get/save the data

Dependency Injection - Spring creates and connects the objects needed for app
